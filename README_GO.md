# Razdel для Go

Это Go-версия библиотеки [razdel](https://github.com/natasha/razdel) для токенизации и сегментации русского текста.

## Установка

```bash
go get github.com/natasha/razdel
```

## Использование

### Токенизация

```go
package main

import (
	"fmt"
	"github.com/natasha/razdel"
)

func main() {
	tokens := razdel.Tokenize("Кружка-термос на 0.5л (50/64 см³, 516;...)")
	for _, token := range tokens {
		fmt.Printf("%s\n", token.Text)
	}
}
```

### Сегментация на предложения

```go
package main

import (
	"fmt"
	"github.com/natasha/razdel"
)

func main() {
	text := `- "Так в чем же дело?" - "Не ра-ду-ют". И т. д. и т. п. В общем, вся газета`
	sents := razdel.Sentenize(text)
	for _, sent := range sents {
		fmt.Printf("%s\n", sent.Text)
	}
}
```

## API

### `Tokenize(text string) []Substring`

Разбивает текст на токены.

**Параметры:**
- `text` - исходный текст для токенизации

**Возвращает:** слайс объектов `Substring`, каждый из которых содержит:
- `Start` - начальная позиция токена в исходном тексте
- `Stop` - конечная позиция токена
- `Text` - текст токена

### `Sentenize(text string) []Substring`

Разбивает текст на предложения.

**Параметры:**
- `text` - исходный текст для сегментации

**Возвращает:** слайс объектов `Substring` с информацией о предложениях

## Особенности реализации

Эта Go-версия сохраняет функциональность оригинальной Python версии, но использует идиоматичные Go-практики:

- Использование интерфейсов вместо классов
- Структуры данных вместо объектов Python
- Пакетная архитектура вместо модулей Python
